# DesktopClock 桌面时钟

一款 **单文件 WPF 桌面时钟**（Windows），集霓虹渐变视觉、街道级实时天气、贴心的右键菜单于一体。全部功能装在一个 `DesktopClock.cs` 里，无需 Visual Studio，双击 `build.bat` 即可编译。

当前版本：**v1.7**

![DesktopClock 运行效果](screenshot.jpg)

*实机截图：暖金渐变的时/分 + 玫瑰粉渐变的秒（华文琥珀字体），左上角为街道级实时天气*

## ✨ 功能特性

### 时钟显示
- **时 / 分 / 秒** 大数字采用 **白→暖金 / 浅粉→玫瑰粉 渐变字体**，配暖光晕，与紫→青冷色背景形成色相对撞
- **华文琥珀** 圆润可爱字体（回退：幼圆 → Comic Sans MS），日期/天气同步风格
- 超椭圆（squircle）圆角面板，圆角大小 0~150 可调
- 霓虹紫青对角渐变背景 + 斜向高光带 + 磨砂颗粒质感，不透明度可调

### 自定义背景图（v1.7 新增）
- **两种导入方式**：把图片直接**拖到时钟上**，或右键菜单「选择背景图片…」
- **四种缩放模式**：填充裁剪 / 适应留边 / 拉伸铺满 / 平铺
- **暗化遮罩**（0~80%）：保证复杂照片上时间文字依然清晰
- **模糊强度**（0~30px）：虚化照片当背景，夜景色调很高级
- 图片层自动继承圆角裁剪；图片被删除或移动时**自动回退渐变背景**，不会报错

### 天气（全自动）
- **街道级精度**：输入"昆明 官渡区 吴井路"这样的地址，通过 Photon（OSM）地理编码到街道坐标
- 天气数据来自 **Open-Meteo**（免费无 key），自动匹配最优气象模型
- 每 **10 分钟** 自动刷新；改城市立即刷新
- 中文天气状态 + 图标（☀ 晴 / ⛅ 多云 / ☂ 雨 / ❄ 雪 / ⚡ 雷暴…）
- 多级容错：Photon 编码 → Open-Meteo 编码 → wttr.in 兜底；失败时显示 `[v2]` 开头的全链路诊断信息

### 桌面体验
- 无边框窗口，拖拽任意位置，位置自动记忆
- 可选窗口置顶、显示/隐藏秒
- 右键菜单直接调整所有设置，**无需手编配置文件**

## 🚀 快速开始

1. 双击 `build.bat` 编译（使用系统自带的 .NET Framework 4.x 编译器，无需安装任何东西）
2. 双击 `DesktopClock.exe` 运行
3. 右键点击时钟 → **设置城市…** → 输入你的地址（如 `昆明 官渡区 吴井路`）→ 回车
4. 想换背景：**把一张图片拖到时钟上**，完事

> 💡 提示：地址层级之间用**空格**分隔；只写"吴井路"也能查到，但带上城市名更准。

## 🖱 右键菜单说明

| 菜单项 | 功能 |
|---|---|
| 背景不透明度 | 滑块调节背景透明度（0.30~0.95） |
| 描边强度 | 边缘高光强度（0~0.40） |
| 圆角大小 | 超椭圆圆角半径（0=方角，150=半圆） |
| 窗口置顶 | 始终显示在最上层 |
| 显示秒 | 显示/隐藏秒数 |
| 背景图片 | 显示当前背景图文件名（或"渐变背景"） |
| 选择背景图片… | 打开文件对话框选择图片 |
| 清除背景图片 | 回到霓虹渐变背景 |
| 缩放模式 ▸ | 填充裁剪 / 适应留边 / 拉伸铺满 / 平铺 |
| 背景暗化 | 遮罩强度滑块（0~0.80） |
| 背景模糊 | 模糊半径滑块（0~30px） |
| 天气城市 | 显示当前城市 |
| 设置城市… | 弹窗输入新城市（回车确定，ESC 取消） |
| 自动定位 (IP) | 清除手动城市，恢复 IP 自动定位 |
| 退出 | 关闭程序（自动保存位置） |

所有设置（含窗口位置）会自动保存到 `settings.json`，下次启动自动恢复。

## ⚙ settings.json 配置项（可选手动编辑）

```jsonc
{
  // 背景不透明度 (0.30 ~ 0.95)
  "tint": 0.796,
  // 高光描边强度 (0.0 ~ 0.40)
  "edge": 0.4,
  // 圆角半径（0 = 方角，150 = 半圆）
  "corner": 110.804,
  // 天气城市：留空 = 自动 IP 定位；街道级精度用空格分隔层级
  "city": "昆明 官渡区 吴井路",
  // 背景图片路径（留空 = 渐变背景）
  "bgImage": "C:\\Users\\Lenovo\\Pictures\\wallpaper.jpg",
  // 背景图缩放模式：fill / fit / stretch / tile
  "bgFit": "fill",
  // 背景图暗化遮罩强度（0.0 ~ 0.80）
  "bgDim": 0.30,
  // 背景图模糊半径（0 ~ 30 像素）
  "bgBlur": 0.0,
  // 窗口置顶
  "topmost": true,
  // 显示秒
  "seconds": true,
  // 窗口位置（像素）
  "x": 530.667,
  "y": 370.667
}
```

支持 `//` 注释。修改后**保存即生效**（热重载，无需重启程序）。

## ❓ 常见问题

**Q：天气一直"获取中"或显示错误？**
天气区域会显示 `[v2]` 开头的具体错误（如 `IP定位失败`、`OpenMeteo失败: ...`），按提示排查。多数情况是代理或网络问题，等下一轮 10 分钟刷新会自动重试。

**Q：开了代理（尤其 Clash/v2rayN 的 TUN 模式）后自动定位的城市不对？**
TUN 模式接管全部网络流量，IP 定位会识别成代理节点的位置，这是原理性限制。**解决方案：右键 → 设置城市… 手动填地址**，完全不依赖 IP。

**Q：天气想精确到街道？**
设置城市时用空格分隔层级，如 `北京 海淀区 中关村`。只写区县（`官渡区`）或路名（`吴井路`）也可以。

**Q：背景图怎么设置？**
两种方式：① 直接把图片文件**拖到时钟窗口上**（推荐，最快）；② 右键 → 背景图片 → 选择背景图片…。菜单里还能切换缩放模式、调暗化和模糊。

**Q：换成背景图后时间文字看不清？**
调高「背景暗化」（建议 0.3~0.5），或加一点「背景模糊」。暗化是把图片压暗，时间文字始终在上层，所以越暗越清晰。

**Q：背景图没显示出来 / 变成渐变了？**
图片被移动、删除或路径失效时会自动回退渐变背景（这是设计行为，不会报错）。重新拖一张或菜单里重选即可。

**Q：背景图会把我的图片复制到程序目录吗？**
不会。程序只记录图片的**绝对路径**，不复制文件。所以别随意移动原图——移动后需要重选。

**Q：编译报错？**
确认使用的是 `build.bat`（含正确的引用参数）。本项目代码严格兼容 .NET 4.x 自带的 C# 5 语法。

**Q：想换字体？**
编辑 `DesktopClock.cs` 中 `CreateTextBlock` 里的 `FontFamily`，当前为 `华文琥珀 → 幼圆` 回退链。

## 🛠 技术要点

- .NET Framework 4.x + WPF，纯代码构建 UI（无 XAML），严格兼容 **C# 5** 语法
- 超椭圆用四段贝塞尔曲线解析构造，曲率连续无突变
- 背景是分层 Canvas：图片层 → 渐变层（有图时隐藏）→ 暗化遮罩 → 磨砂颗粒，圆角由 squircle 裁剪统一生效
- 图片加载用 `DecodePixelWidth` 降采样到 2 倍窗宽，4K 大图也不卡；`BitmapCacheOption.OnLoad` 读完即释放文件句柄
- 天气链路：Photon 地理编码（街道级）→ Open-Meteo 天气 API → wttr.in 兜底，全链路错误诊断
- `settings.json` 自实现 JSON5 风格解析（支持注释 + 标准转义，含 Windows 路径反斜杠），save/load 往返幂等
- `FileSystemWatcher` 实现配置热重载
